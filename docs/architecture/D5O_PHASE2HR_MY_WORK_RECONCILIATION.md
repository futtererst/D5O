# Phase 2H-R My Work reconciliation

`d5o_hosted_role_actions_v1` supplies hosted role context. The previous tenant-neutral list labeled every row `view_only`, including actionable Design reviews. Phase 2H-R derives the Design preparation, document, package-review and release responsibilities from the latest hosted Work Design projection, and the existing receipt task from accepted release state. Generic hosted role rows for other phases remain context links.

An employee opens the same Work phase component from My Work or from the Work directory. After a successful action the client reloads the list, Work detail and phase projection. A completed document or review no longer appears as a pending action; the next actor sees the new responsibility after loading their own tenant-scoped list. The list does not grant permission. Server scope and the hosted command recheck actor, role, tenant, Work identity, evidence and current revision.

Stale tasks are resolved by the hosted command's conflict response and a fresh projection read. Package-review tasks and reviewer forms are filtered to the **current package revision**. A method correction increments that revision, so the old approved reviews and crew demand cannot release the revised package; fresh decisions are required. A revoked membership or suspended tenant is denied by `customerWorkScope` and the hosted command, though these new-route cases still need direct HTTP qualification. The Design release remains blocked until the command confirms the required package basis, issued document, dated crew demand and independent reviews. Task status is derived; no independent task-completed table was added.

Known limitation: the Design handoff preparation commands remain outside the tenant-neutral customer Work actions in this package. The connected browser fixture starts from an authorized, accepted Define and Design handoff, then performs package preparation through independent receipt in the browser. Develop, Deploy and Operate action integrations remain separate packages.
