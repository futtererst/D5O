# Phase 2H-V employee action coverage

The six customer-facing phases remain Discover, Define, Design, Develop, Deploy and Operate. This package changes only the Operate employee surface and the My Work projection. It leaves the existing provisioning, configuration publication, tenant lifecycle, entitlement, connected service and Deploy command implementations in place.

| Phase or concern | Employee coverage used by this journey | Evidence |
| --- | --- | --- |
| Administration and configuration | Two independent fictional tenants, role grants, published thresholds and pinned policies | Two-tenant runner setup and direct RPC checks |
| Discover and Define | Work intake, draft, independent review and handoff | Inherited executable runner gates |
| Design | Accepted package, offer, estimate and release | Inherited executable runner gates |
| Develop | Qualified crew, publication and field-start authority | Inherited executable runner gates |
| Deploy | Field result, independent evidence review, completion and whole-Work customer acceptance | Inherited browser steps and private evidence checks |
| Operate | My Work handoff, supported asset, documentation supply/review, support acceptance and activation | Phase 2H-V authenticated browser steps and Operate RPC state |
| Financial outcome | Pending closeout remains distinct from Active support; Finance receives a task to start existing `In review` state | Operate browser state, finance task and phase projection |

The Operate page does not implement an invoice, receivables, general support-ticket or new workflow engine. Financial closeout cannot be represented as complete without its separate authoritative record. Historical production data, protected staging and commercial email delivery are outside this local qualification.
