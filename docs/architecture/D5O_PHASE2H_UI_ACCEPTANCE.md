# Phase 2H UI acceptance

The existing tenant-neutral Work page now shows a My Work section ahead of the directory. Define decision tasks link to the exact Work and phase. The Define section shows current scope status, requires a decision reason and offers only server-projected independent review or handoff actions for the signed-in actor. Loading, RPC error and refresh behavior reuse the Phase 2G Work component. Other hosted role-queue items link to business context and are explicitly labelled **View context**; their execution controls are not yet available here.

Browser acceptance is **partial**. The dedicated authenticated fixture exercised all four Define decisions for each tenant after opening each My Work link, and captured before/after screenshots in `evidence/phase2h-browser/`. The before images show the My Work item, correct Work, current phase, reason field and permitted action. The after images show task removal and refreshed authoritative status. `a-define-commercial-mobile-before.png` and its Tenant B equivalent capture the actual responsive decision form at 390 px. Desktop and mobile screenshots from the inherited readback fixture represent actual application sessions, but do not prove later phase decisions were browser-executed.
