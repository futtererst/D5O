# Phase 2H-S security results

## Executed in disposable Supabase

`evidence/phase2hs-design-gate-results.json` reports 37 passing checks, zero failures, and verified cleanup. Private Design PDF reads verify the actual object bytes, registered size, and SHA-256. Invalid, foreign and receipt-free object references return HTTP 422; a deleted object returns 404 and cannot be reviewed. An issue attempted before review returns `42501`. A pair of conflicting demand decisions returns one HTTP 200 and one 409 for each tenant. A disabled `connected_work` flag returns API 403 and direct Design RPC `42501` without changing the decision revision. Cross-tenant, forged Work, stale, wrong-role, suspended membership, removed membership, and suspended tenant denials are also recorded.

`evidence/phase2hs-develop-gate-results.json` reports 40 passing checks, zero failures, and verified cleanup. Its Develop security check records cross-tenant GET 403, forged Work POST 404, wrong-package POST 409, foreign-resource RPC `23514`, stale crew RPC `23505`, duplicate field-start POST 200 with unchanged Deploy revision, disabled-feature direct workforce RPC `42501`, and disabled-feature Develop API 403 with unchanged workforce revision. Existing field-start checks deny the tenant administrator and a foreign Operations actor with `42501`. Booking an unqualified worker returns `23514`; separate negative bookings reach the exact `worker_unavailable_for_shift` and `worker_weekly_capacity_exceeded` errors before authorized scheduling. These checks use actual authenticated sessions and command RPCs, with state inspected after denied mutations.

The capability gates are local migrations `20261024105438_phase2hs_connected_design_capability_gate.sql` and `20261024113000_phase2hs_connected_develop_capability_gate.sql`. They protect the existing tenant-owned connected Design, crew, workforce, commercial authority and field-start decisions from a direct RPC when `connected_work` is disabled. The existing connected Work creation RPC already checks the capability. The older generic Work table and shared prototype state are intentionally outside the new trigger: an initial broad trigger broke the inherited Phase 2B and 2C generic Work regressions, so it was narrowed before delivery. They do not remove the Rybex/Rotork pilot route restrictions. The overnight crew migration aligns an existing cross-midnight field-start rule with crew eligibility; it also checks next-day absence and weekly capacity.
