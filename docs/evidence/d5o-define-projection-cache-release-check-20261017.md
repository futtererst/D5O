The typed Define decision separately binds exact source and decision revisions. This is an **explicit stale-state rejection contract**, not an automatic merge contract. A user must compare the current basis and deliberately re-enter applicable draft changes. Neither approved requirements nor a competing decision may be silently replaced.

Source inspection found a distinct editor-recovery defect: on HTTP 409 the editor kept the unsaved React state but told the user to refresh; refresh fetched the shared snapshot and discarded that state. The current-state read checks whether the exact retained Define draft already committed; if so, the UI says not to retry and clears the recovery copy.
