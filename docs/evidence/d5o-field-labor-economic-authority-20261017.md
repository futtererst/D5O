## Business boundary implemented

An admin independently approves a Work-scoped labor sublimit and fully burdened prototype rate under the existing parent Work authority. A scheduler can save and revise a draft booking with explicit **person-hours per worker**, which consumes no economic authority. The existing governed publication command checks the current release, demand, booking identity, bound eligible workers, labor authority, rate validity, category headroom and parent Work cap under the Work lock. Publication creates one reservation per worker. Identical retry retains its receipt; an amendment must carry the current assignment and source revisions. Worker acknowledgment and field-start permission remain separate. The exact reviewed field report is the source of incurred labor cost. Its later independently reviewed correction is retained as a signed cost adjustment, not a second shift. A factual overrun can increase actual cost beyond the original reservation without retroactively approving more work. Outstanding commitment is the positive difference between active reservation and current reviewed incurred cost; consumed Work authority uses the larger of these values. Finance shows both, and workers cannot read the sensitive authority endpoint.

Manual Finance Labor entry remains available for legacy work without governed labor authority. With approved governed authority, the typed command rejects that generic cost path and the UI removes its Labor option. This avoids counting the same reviewed hours twice. Production rates, burden, funding and delegation were **not** configured.
