# D5O task presentation inventory

Shawn's direct feedback on 2026-10-11 is that every page exposes too much information. This inventory covers the routed and embedded surfaces in the connected prototype. The default hosted entry is My Work. Phase and reference pages remain available as secondary browsing for relevant roles; a queue link opens the exact Work, source and revision. Visibility is a presentation choice, not permission to commit a command.

| Surface | Relevant users and primary task | Essential first view | Secondary context |
| --- | --- | --- | --- |
| Work hub / home | PM, Operations, supervisor, Finance: orient to assigned decisions | Next task, blocker, owner | Portfolio measures, legacy observations |
| My Work | All authenticated roles: find the next permitted action | Action needed, preparation, waiting, exact task link | Owned Work Records and informational handoffs |
| Discover | PM, commercial: qualify a customer pursuit | Customer/site, pursuit decision, missing facts | CRM history, pipeline and forecast |
| Define | PM and independent reviewers: approve exact baseline | Submitted revision, requirements, scope, review decision | Earlier baselines and full register |
| Develop / Commercial | PM and commercial reviewer: price and approve offer/change | Exact estimate or proposal, source, authority, blocker | Rates, prior commercial history |
| Design | Engineering and Operations: review and release exact package | Package revision, governing documents, review and release blocker | Full document index, configuration and history |
| Deploy | Worker, supervisor, Quality and Operations: execute/review exact package | Release, safety/access, submitted fact, failed test, permitted decision | Forecast, other packages, report and evidence history |
| Operate / service | PM, Operations and Finance: receive support or decide request/finance | Exact request or handoff, current cycle and decision | Asset, agreement, maintenance and prior-cycle history |
| Work Record Overview/Readiness | Accountable role: understand current position | Current decision and blockers | Full phase journey, metrics, legacy progress |
| Work Record Evidence/Issues/History/Lifecycle | Relevant role: inspect proof, resolve condition or review history | Exact linked source and action | Full evidence register and prior decisions |
| Worker schedule and reporting | Assigned worker: acknowledge, read instructions, report work | Booking, approved release, safety, task and sync state | Other shifts and prior reports |
| Crew schedule / People & capacity | Scheduler/Operations: fill a qualified booking | Uncovered demand, availability, conflicts | Full calendar, roster and utilization |
| Execution register / Handoff register | Supervisor/Operations: locate current package/receipt | Current scope, verification, receipt and next owner | Historical releases, prior acceptance |
| Support queue / service Finance | PM, Operations, Finance: resolve exact request obligation | Current-cycle pricing/terms/decision, outstanding amount | Agreement history, costs and invoices |
| Finance / billing | Finance: review bill, cost or receivable | Accepted scope, source, balance, permitted decision | Ledger history and cost detail |
| Portfolio / Decision queue / Insights | Manager or auditor: inspect work across records | Filters and exceptions | Aggregate metrics and drilldown |
| Evidence library | Reviewer or auditor: retrieve exact retained source | Work/package, state, file identity | Full custody register and history |
| Workspace configuration / Operating model / Worker access | Administrator: maintain policy and access | Selected administration task and its current state | Published versions, synthetic fixtures and audit context |
| Start Work | PM/admin: create a governed identity | Customer, site, work type, owner | Configuration pin and detailed lifecycle reference |

The shared navigation places daily tasks first and folds phases, reference views and administration behind named disclosures. Hosted My Work consolidates the authenticated queue projections; record ownership is no longer counted as an actionable task. Exact linked tasks suppress the generic phase journey and decision rail while preserving an explicit full-record exit. Individual command forms still require a current server-side authority decision. Detailed phase and reference pages remain available as secondary views, and their deeper progressive disclosure needs direct user retesting rather than an assumed usability pass.
