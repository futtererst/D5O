# RC13-A security, integrity and recovery

Genuine fictional GoTrue sessions showed same-tenant private evidence retrieval and the negative boundaries recorded in the evidence report. Wrong-role administration and independent Define/Develop reviews were denied (HTTP 403). Invalid configuration version returned 409; direct privileged evidence RPC returned 403. Define exact replay returned its original successful result; conflicting command reuse returned 409. A direct attempt to bypass the protected customer decision was rejected by a database trigger. A `customer-work` route request returned `pilot_route_required`, so My Work remains unqualified rather than counted as a denial pass.

The isolated database retained its 202 actual migration entries, 82 copied Auth provider version identifiers, and 33 Auth users including eight fictional actors. The 236 source-migration checksums and both RC8 bridge checksums match. Original protected projection entries were unchanged: 15 catalog entries, 18 Work entries in one workspace and three in the other. The historical row multiset comparison found seven full-row exceptions. Six reflect added migration columns, appended fictional data or affected row metadata; original keys were preserved and no preexisting field changed in the six reviewed business tables. The seventh is two changed `storage.migrations.hash` values from local Storage API startup and is a **provider-managed metadata difference**, not business history. This exception remains disclosed. All 23 protected object hashes matched; zero foreign keys were unvalidated.

The original encrypted checkpoint was independently restored in a network-isolated local container in **18.65 seconds**, with 177 ledger entries, 25 original Auth users, and 23 Storage metadata rows. This is a local measurement, not production RTO/RPO. The database and private bytes were captured at different production instants, so coordinated production recovery and cutover consistency remain unqualified. RC8/RC12 injected migration rollback evidence remains the applicable interrupted-upgrade result; RC13-A did not repeat those prior injections.
