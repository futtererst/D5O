# RC3-C Design and Develop My Work navigation

The customer Work page now carries the selected My Work task ID in its link. It checks the current actor's queue and Work identity before displaying the assigned responsibility and its action context. A forged or completed ID displays a stale-responsibility warning. The query parameter does not authorize a command; existing role, tenant, revision, evidence and configuration checks still decide mutations.

The final authenticated browser result is [`evidence/D5O_RC3C_TWO_TENANT_BROWSER.json`](evidence/D5O_RC3C_TWO_TENANT_BROWSER.json). It records **85 task-link openings** with actor, tenant, Work, title, href and task ID. The Design runner opened My Work links for awarded handoff submission/receipt, package creation, document preparation/upload/submission/review/issue, package-basis work, crew demand, all four review requests and independent decisions, release, and independent package receipt. Existing broad “Complete and release Design package” responsibility covers its preparation steps; the form and business command remain unchanged. The action array explicitly marks 47 Design command decisions as link-originated. The two private PDF uploads and two package receipts were also entered through assigned links; their older per-action record format lacks that flag, while `browserTasks` retains the exact links.

Develop authority, booking, publication and field-start decisions used assigned My Work links with task IDs (14 recorded action decisions). The two field-worker acknowledgments used the existing assigned worker schedule/field page, which is a separate employee responsibility surface rather than a customer Work panel decision. Each linked decision retained its authoritative response, and the runner checked queue changes, reload, configuration pins and phase replay.

The final browser check submitted a random forged Design task ID and replayed a completed Design handoff task link. Both displayed “This responsibility is no longer available,” neither ID appeared in the actor's queue, and the Design revision and Work configuration pin remained unchanged. Cross-tenant, removed-member, suspended-member, disabled-feature and stale command denials are recorded in the same result.
