**Production execution remains a stop.** The 58 hosted-linked SQL formatting differences now have conservative token-level equivalence evidence. The 44 absent early source effects, 19 version remappings and 10 unmatched legacy effects still need reconciliation. A production runner must use the actual hosted ledger and record each executed statement atomically, with a protected checkpoint, bounded write freeze, lock/statement timeouts, first-error stop and recovery plan. It must never run the 44 early files merely because their source version is absent, or insert synthetic history to satisfy a clean-install tool.

Preconditions: approved project identity; 177-entry ledger and immutable SQL/hash baseline; exact one linked historical invitation; no unexpected affected rows, trigger or table drift; verified Auth/Storage checkpoint; and reviewed privileges. Stop on any failed constraint, ledger mismatch, RLS/grant change, Work pin/event/receipt/evidence mismatch, permit ambiguity or private-byte hash mismatch. The local runner is qualification evidence, not an authorization to migrate production.
