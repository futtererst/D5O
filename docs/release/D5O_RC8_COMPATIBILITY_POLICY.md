# RC8 historical invitation compatibility policy

**Chosen: preserve completed history and constrain future proposals.** The original `requested_role='field_worker'`, `status='setup_completed'`, invitation identity, timestamps, provider-user link, fingerprint and active membership remain unchanged at transaction commit. No customer approval or business meaning is normalized away.

The [precondition SQL](../../scripts/rc8_bridge_pre_215.sql) requires exactly one completed legacy proposal, a matching Auth user and active field-worker membership, the prior absence of tenant provisioning, no preexisting order-215 ledger row, and no enabled invitation trigger. It stores the original values in a transaction-local table and temporarily sets only `requested_role` to null. Frozen order 215 then installs its check. The [postcondition SQL](../../scripts/rc8_bridge_post_215.sql) replaces that check with one that also permits a field-worker proposal when `provisioning_workspace_id` is null, and installs a guard denying such proposals for a workspace with a `tenant_provisioning` row. It restores the original role, proves the selected history columns match, and writes a private, RLS-protected bridge receipt. All steps and the order-215 ledger insert commit or roll back together.

The guard retains the existing pilot proposal route without allowing a new provisioned tenant to use it. A synthetic provisioned-tenant test returned SQLSTATE `42501`; a pilot no-op update passed. The guard function has no public/anon/authenticated/service-role execute grant. The receipt table has RLS and no read grant to those roles. This is a release compatibility policy for the existing contract, not a new membership-granting workflow. The bridge still requires a bounded application write freeze and reviewed execution privileges at real cutover.

Options rejected: changing the stored historical role/status would damage provenance; appending a correction after migration 236 cannot unblock order 215; a `NOT VALID` constraint would leave the historical violation unresolved. No production change was made.
