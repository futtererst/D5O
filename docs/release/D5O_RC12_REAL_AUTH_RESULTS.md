# RC12 real Auth results

**PASS for local genuine GoTrue sessions, with a checkpoint-consistency limit.** The authorized encrypted checkpoint restored 25 historical Auth users and identities, but `auth.schema_migrations` contained zero rows. A production **read-only** metadata query found 82 provider versions, latest `20260831180000`. The restored and production Auth catalogs each had 271 logical columns with the same order-independent digest. The 82 exact version identifiers were copied to the isolated database; their digest matched production. No provider migration row was invented. Official cached GoTrue v2.195.0 then started and remained healthy without changing the Auth column digest or 82-row provider ledger. See [provider reconciliation](evidence/D5O_RC12_AUTH_PROVIDER_RECONCILIATION.json). Supabase's [self-hosting restore guide](https://supabase.com/docs/guides/self-hosting/restore-from-platform) documents the need to configure Auth separately when restoring a project.

Two fictional users were created through GoTrue sign-up. Password login returned genuine sessions; HMAC signatures, `authenticated` role, subject, expiry and `/user` identity were verified. The frozen application's production build accepted both browser sign-ins. Their local memberships granted only their fictional tenant roles; no historical customer's password, session or invitation changed. An existing browser session lost Work and evidence access after its membership was marked `removed`. Suspended membership and a disabled fictional tenant each returned 403 with 200 positive controls. [Session](evidence/D5O_RC12_AUTH_SESSION.json), [application HTTP](evidence/D5O_RC12_APP_REAL_AUTH_HTTP.json), and [suspension](evidence/D5O_RC12_SUSPENSION.json) results are sanitized.

The provider ledger was obtained after the original checkpoint. Its exact state at that checkpoint instant is **UNKNOWN**, although the logical Auth schema matched the current production catalog. This limits claims about an atomic historical Auth checkpoint; it does not negate the observed local GoTrue compatibility. Production Auth remained read-only.
